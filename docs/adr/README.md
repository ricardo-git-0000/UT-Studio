# Registro de decisiones

“Aceptado” recoge restricciones ya establecidas por el contexto, no una aprobación nueva de bibliotecas o detalles pendientes. Las propuestas evolucionan mediante nuevos ADR que indiquen cuál sustituyen.

- [0001-portable-architecture](0001-portable-architecture.md): Núcleo portable y adaptación WPF.
- [0002-bounded-pipeline](0002-bounded-pipeline.md): Canales acotados y saturación observable.
- [0003-incremental-storage](0003-incremental-storage.md): Persistencia incremental recuperable.
- [0004-neutral-reporting](0004-neutral-reporting.md): Informe neutral y decisiones tecnológicas diferidas.

La distribución exacta en proyectos y las elecciones de librerías siguen abiertas; véanse [arquitectura](../architecture/overview.md) y [cuestiones](../requirements/open-questions.md).
