# Resúmenes de progreso

Este directorio contiene resúmenes opcionales de fases o funcionalidades
importantes del proyecto.

No contiene transcripciones completas de conversaciones.

Los resúmenes no sustituyen los requisitos, la documentación de arquitectura
ni los ADR; la información duradera debe mantenerse en esos documentos.

Las decisiones arquitectónicas deben documentarse en `docs/adr/`.
